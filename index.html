Pysh (PYthon SHell)

This shell is a python based terminal shell.

Pysh is a shell made out of pure python.

Reasons to use Pysh:

1. It has native pyexe and pypub functions for python development

2. It has native configuration

3. It has native uv support

4. It has its own implementation of the bat function (view)

5. It can run python scripts ending in .pysh or .py directly

Pythoner

Pythoner was extracted from pysh, it is a custom python REPL that has native UV and pip support.
