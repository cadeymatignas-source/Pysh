Pysh (PYthon SHell)

This is a shell coded entierly out of Python

Pysh is a Python-based shell tailored for Python development.

Reasons to use Pysh:

1. It has native pyexe and pypub functions for python development
2. It has native configuration
3. It has native uv support
4. It has its own implementation of the bat function (view)
5. It can run python scripts ending in .pysh or .py directly

Pythoner

Pythoner is another related project. It is a custom python REPL designed to combine python and package handling in one tool.
It was extracted from pysh.
